# WaveStay - Island Rental Platform

Platform web pemesanan fasilitas liburan pulau (Villa, Speedboat, Jetski, dan Snorkeling) berbasis PHP, Tailwind CSS, dan MySQL.

## Cara Menjalankan Aplikasi
1. Pastikan aplikasi Laragon sudah terinstal dan aktif (Start All).
2. Masukkan folder projek `wavestay` ke dalam direktori root Laragon (`laragon/www/wavestay`).
3. Buat database baru bernama `wavestay` di phpMyAdmin, lalu import file `wavestay.sql`.
4. Buka browser dan akses link: `http://wavestay.test`

## Akun Admin Default
- Username: `admin`
- Password: `password123` (atau sesuai yang sudah kamu ganti)
